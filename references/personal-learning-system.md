# 个人学习系统通用说明 V1.0

## 1. 核心学习特征

该学习者不是传统的"章节---记忆---练习"型学习者，而是：

> 问题驱动 + 结构导向 + 反例敏感 + 跨领域迁移 + 自我模型重构型学习者。

学习目标不是单纯积累知识，而是：

> 获得对世界的解释力，以及对自己判断过程的控制权。

------------------------------------------------------------------------

## 2. 底层驱动力

### 2.1 认知主权

不接受"别人这样说所以如此"。

必须理解： - 为什么成立 - 前提是什么 - 边界在哪里 - 何时失效 -
是否存在反例

目标：

> 将知识从"别人告诉我的东西"转化为"自己能够重建的模型"。

### 2.2 复杂性压缩

偏好寻找不同领域之间的结构同构。

学习奖励来自：

> "原来这些不同现象底层是同一个结构。"

### 2.3 不确定性控制

天然关注： - 漏洞 - 边缘案例 - 极端情况 - 规则失效点 - 被模型遗漏的人

不仅解释通常情况，也必须说明失效条件。

### 2.4 自我模型更新

学习经常回到：

> "这是不是解释了我为什么这样想？"

------------------------------------------------------------------------

## 3. 最优教学流程

每个模块：

问题 → 初始判断 → 最小模型 → 定义 → 反例 → 边界 → 跨域连接 → 自己解释 →
精确表达 → 固化

------------------------------------------------------------------------

## 4. 从问题开始，而不是定义开始

不要直接输入定义。

先提供有张力的问题，让学习者形成直觉判断。

问题负责启动探索，定义负责整理思考。

------------------------------------------------------------------------

## 5. 先骨架，后细节

先建立： - 核心问题 - 关键变量 - 基础结构

再补充历史、细节和扩展。

------------------------------------------------------------------------

## 6. 每个理论必须允许被攻击

提供： - 最强反例 - 边界案例 - 隐含假设 - 失败条件 - 竞争解释

鼓励主动攻击理论。

------------------------------------------------------------------------

## 7. 跨领域迁移

每个重要概念回答：

> 这个结构还在哪里出现？

建立： - 文学 ↔ 政治 - 投资 ↔ 决策 - 个人经验 ↔ 哲学问题

等连接。

------------------------------------------------------------------------

## 8. 防止分支爆炸

维护：

### 当前主线

当前正在解决的问题。

### 问题停车场

保存其他有价值问题，不立即展开。

每次只允许少量主动分支。

------------------------------------------------------------------------

## 9. 明确"现在不需要知道什么"

防止：

"还有很多不知道" = "我没有学会"。

明确当前阶段的完成边界。

------------------------------------------------------------------------

## 10. 记忆系统

禁止：

阅读 → 阅读 → 阅读

采用：

输入 → 主动回忆 → 修正 → 延迟复现

重点：

> 保留模型，而不是背诵所有文字。

------------------------------------------------------------------------

## 11. 卡住处理流程

使用：

Think → Hint → Reveal → Diagnose

### Think

给予独立思考时间。

### Hint

提供最小提示。

### Reveal

公布完整解释。

### Diagnose

判断困难来源： - 前置知识不足 - 忘记信息 - 定义模糊 - 因果错误 -
迁移失败

------------------------------------------------------------------------

## 12. 表达精度训练

当前特点：

理解能力 \> 精确表达能力。

训练流程：

1.  用自己的话解释
2.  提取关键词
3.  形成正式定义
4.  修正语言
5.  延迟复述

定义结构：

> 上位类别 + 核心机制 + 区别特征 + 边界条件

------------------------------------------------------------------------

## 13. 双语言表达系统

保存两套表达：

### 我的语言

保留个人风格。

例如：

> 别把人当弃子。

### 精确语言

转换为正式表达：

> 不应将特定个体遭受的重大损失视为实现总体利益时可接受的代价。

------------------------------------------------------------------------

## 14. 复习设计

避免大量机械复习。

优先：

-   重建结构
-   举例
-   跨领域迁移

------------------------------------------------------------------------

## 15. 学习完成标准

不要使用：

"全部学完"。

改为：

本阶段是否能够： - 解释核心概念 - 举例 - 找反例 - 迁移应用

完成即可进入下一层。

------------------------------------------------------------------------

## 16. 进度展示

不要使用百分比。

展示：

-   已拥有模型
-   模型之间的连接
-   长期问题图谱

------------------------------------------------------------------------

## 17. 防止辍学

不要使用连续打卡。

中断后：

-   不惩罚
-   快速恢复
-   重新建立上下文

------------------------------------------------------------------------

## 18. 每次学习结束生成

包括：

1.  今天学到了什么
2.  哪个旧理解被修改
3.  当前模型
4.  一个反例
5.  一个跨领域连接
6.  未解决问题
7.  我的表达
8.  精确表达

------------------------------------------------------------------------

## 最终目标

不是学习更多课程。

而是提高：

-   理解能力
-   模型重建能力
-   质疑能力
-   迁移能力
-   精确表达能力

最终形成：

> 我能够理解、检验、表达和修改自己的世界模型。
