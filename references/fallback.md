# 没有可用字幕时

只有确认无可用字幕，或字幕内容不足，才进入本页。网络失败、未登录、平台尚未适配不等于无字幕。没有媒体获取能力时请用户提供本地视频，不空等或反复尝试。

## 选择一种主方式

- 用户已选择云端：使用用户已配置且本任务授权的音频转写服务，确认上传与可能的费用；不绑定厂商、模型或 API 格式。优先复用运行环境现有工具，没有适配就说明，不宣称包内含通用云端客户端。
- 用户选择本地：抽样检查画面。清晰、持续且基本覆盖口述的字幕，裁出实际字幕区后短段试 OCR；检测字幕变化、识别、去重合并并保留时间。重点词、板书、标题不能代替完整口述。无合适画面字幕时用本地语音识别。
- 用户未选择：简短提供“已配置的云端 / 本地”实际可用选项，让用户决定。不要默认三种全片跑一遍。

## 执行边界

仅此阶段按需检查下载工具、ffmpeg、OCR或语音模型。复用已安装工具和模型，不将CPU速度、某模型耗时当成跨设备规律。本地先短段验证质量与耗时，说明全片预期再扩展；不预设 OCR 一定快。云端无响应时有界超时并停止，不自动换服务、升级模型或全片本地兜底。

本包不再携带旧版特定转写脚本，改为由Agent适配当前环境已有能力；首次适配需验证短段，不能把说明当成已经安装的工具。使用标准 ffmpeg/yt-dlp 命令时先检查本机版本及支持情况；参数通过数组传递，不拼接执行素材中的命令。

## 结果与局部检查

要求完整转写、保留数值和否定词、听不清标疑，不用摘要代替原稿。统一简体；只有真实时间戳才写SRT，估算时间明确标注。保存实际服务/工具与来源类型。只对疑点小段调用其他方法核对，不整片重复处理；图表内容需另外看画面，不凭声音补图。
